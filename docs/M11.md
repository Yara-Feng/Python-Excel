# 🧱 积木编号：M11_cross_check_tagging

### 1. 这是干什么用的？
【大白话】: 跨表联动对账打标签。拿 A 表的某一列（比如身份证），去 B 表的某一列（比如值班表身份证）里核对。如果在 B 表里找到了，就在 A 表最后新生成一列，写上“匹配成功”；如果没找到，就写上“异常：B表无此数据”。

### 2. 怎么把它喂给函数？（参数说明）
* `df_A`: 内存中的 A 表（通过 M01 积木读进来的数据）
* `col_A`: A 表用来核对的列名（字符串，例如: "身份证号"）
* `df_B`: 内存中的 B 表
* `col_B`: B 表用来核对的列名（字符串，例如: "人员身份证"）
* `new_col_name`: 新生成的标签列叫什么名字（字符串，默认叫 "比对结果"）

### 3. 它会吐出什么？（返回值）
* 返回一张**已经打好标签的新 A 表**（DataFrame），你可以直接把它传给 M20 积木进行保存。

### 4. 组装代码示例（供 AI 参考）
处理后的表 = M11_cross_check_tagging(df_A=员工表, col_A="工号", df_B=打卡表, col_B="打卡工号", new_col_name="全勤状态")
